# Security Policy

## Supported Versions

Currently, only the latest version of the main branch is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please open an issue in the repository detailing the problem. 
For sensitive security issues, please contact the repository maintainers directly if contact information is available, or use the private vulnerability reporting feature on GitHub if enabled.

We try to respond to security issues as quickly as possible.
